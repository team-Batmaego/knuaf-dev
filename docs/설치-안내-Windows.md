### 처음 열 때 "Windows의 PC 보호"가 뜨면

이 앱은 아직 코드 서명 인증서가 없습니다. 그래서 Windows나 브라우저가 내려받기나 처음 실행을 막을 수 있습니다.
앱에 문제가 있다는 뜻은 아니고, **누가 만들었는지 Microsoft가 보증하지 않았다**는 뜻입니다.
안전하다는 뜻도 아닙니다 — **이 저장소의 릴리스에서 받은 파일인지 확인**하고 여세요.

**대부분의 개인 PC**에서는 한 번만 아래대로 하면 다음부터는 그냥 열립니다.

1. 릴리스에서 `knuaf-dev-0.6.2-x64.exe`를 내려받습니다(버전 숫자는 다를 수 있어요).
   - **Chrome으로 받기를 권합니다.** 이번 확인 PC에서는 경고 없이 받아졌습니다. PC 환경에 따라 경고가 나타날 수 있습니다.
   - **Microsoft Edge에서 "일반적으로 다운로드되지 않습니다"로 막히면**: 다운로드 항목 옆의 **… (기타 작업) → 유지**를 누릅니다. 그래도 진행되지 않거나 막히면 **Chrome 브라우저**로 받아 보세요. (보호 기능이나 방화벽을 끄지 마세요.)
   - **64비트 Windows 10/11**용입니다. ARM 노트북은 아직 확인하지 않았습니다.
2. 내려받은 파일을 두 번 눌러 실행합니다. 파란 창
   **"Windows의 PC 보호"** 가 뜨고 **"실행 안 함"** 만 보일 수 있습니다.
3. 그 창에서 **"추가 정보"** 를 누릅니다. 그제야 아래에 **"실행"** 단추가 나타납니다.
   **"실행"** 을 누릅니다.
   - **"추가 정보"가 보이지 않으면**: 내려받은 파일을 **오른쪽 클릭 → 속성** → 맨 아래
     **"차단 해제"** 에 체크 → **확인** → 다시 두 번 누릅니다.
     (차단 해제는 "인터넷에서 받은 파일"이라는 표시를 지우는 것이지, 관리 정책을 푸는 것이
     아닙니다.)
4. 실행 중인 창업논문 도우미에서 작업을 저장하고 앱을 닫습니다. 옛 앱이 열려 있으면 제거 중 강제로 닫힐 수 있습니다.
5. 설치는 바로 진행됩니다. 예전에 **모든 사용자(Program Files)**로 설치한 판이 있으면 제거를 위해 관리자 확인 창이 뜹니다. **예**를 누르면 옛 판이 제거된 뒤 새 판이 내 계정에 설치됩니다. 확인을 **취소하면 새 판은 계속 설치되지만, 옛 판과 그 바로가기(바탕 화면·시작 메뉴)가 남을 수 있습니다.** 옛 바로가기를 없애려면 설정 → 앱 → 설치된 앱에서 이전 버전의 knuaf-dev를 제거하세요. 논문 자료와 앱 데이터는 삭제하지 않습니다.
   - 확인을 취소한 뒤에도 새 사용자 설치의 자동 업데이트는 관리자 확인 없이 진행됩니다.
   - 앱이 끝나면 **창업논문 도우미가 자동으로 열립니다.** 새 판의 바탕 화면과 시작 메뉴 바로가기가 생깁니다.
   - 옛 판 제거에서 취소가 아닌 오류가 나면 설치를 중단합니다. 실행 중인 앱을 닫고 설치 파일을 다시 실행하세요.
   - **앱을 관리자 권한으로 실행하지 마세요.**
6. 첫 화면에서 **쓰고 있는 AI를 연결**합니다. ChatGPT 계정으로 로그인하거나, 이미 설치한
   Claude Code 를 연결하면 됩니다. 이때 **Claude나 ChatGPT의 추가 사용(크레딧 충전)은 켜지 마세요.** 종량제로 추가 요금이 나갈 수 있으니 기본 정액 요금제나 기본 상태로만 사용하세요.

> **학교·회사에서 관리하는 PC**는 보안 정책으로 이런 경고를 건너뛰지 못하게 막아 두었을 수
> 있습니다. 위 방법으로도 계속 막히면 PC 관리자(정보 담당 선생님)에게 물어보세요.

> **"알 수 없는 게시자"** 라는 문구가 보여도 서명 인증서가 없어서 나오는 문구입니다.
> 이 저장소의 릴리스에만 설치 파일을 올립니다. 다른 곳에서 받은 파일은 실행하지 마세요.

### Codex(채팅 도우미)는 앱에 함께 들어 있습니다

윈도우 설치본에는 **Codex CLI 가 함께 들어 있어서 따로 설치할 필요가 없습니다.** (버전을 앱과
맞춰 함께 넣습니다.) 맥은 지금처럼 학생이 직접 설치합니다 — 실험 단계입니다.

처음 한 번만 ChatGPT 로그인이 필요합니다. 앱 첫 화면에서 **Codex 연결**을 누르면 브라우저가
열리고, 로그인하면 그다음부터는 그냥 됩니다. 로그인 정보는 Codex 가 자기 저장소에 보관합니다
(앱이 대신 보관하지 않습니다).

Claude Code(앱 안 터미널)는 **함께 들어 있지 않습니다** — 쓰려면 직접 설치해야 합니다.

내려받은 파일이 중간에 손상되지 않았는지 확인하려면, 릴리스에 함께 올라온
`SHA256SUMS-windows.txt` 와 대조하면 됩니다. PowerShell 에서:

    Get-FileHash -Algorithm SHA256 "$env:USERPROFILE\Downloads\knuaf-dev-*.exe"

### 시작 메뉴에서 앱 찾기·제거 (v0.6.0)

- 시작 메뉴에서 **창업논문 도우미**를 검색하세요. 시작 메뉴·바탕 화면 바로가기 이름은 **창업논문 도우미**입니다.
- 설치를 지우려면 설정 → 앱 → 설치된 앱에서 **창업논문 도우미**를 찾아 제거합니다. 앱 목록에는 이름 뒤에 버전 번호도 표시됩니다. 이전 판은 **knuaf-dev** 또는 **KNUAF-Dev · 창업논문 작성 도우미**로 표시될 수 있습니다.
- **"창업논문 도우미 앱을 제거할까요?"**에서 **확인**을 누르면 제거를 진행하고, **취소**를 누르면 중단합니다.
- 앱이 열려 있으면 먼저 작업을 저장하세요. 실행 중 안내에서 **확인**을 누르면 앱이 닫히며, 저장하지 않은 내용은 사라질 수 있습니다. 논문 작업 폴더와 그 안의 자료는 지워지지 않습니다.
- 실행 파일명은 업데이트 호환성을 위해 **KNUAF-Dev · 창업논문 작성 도우미.exe**로 유지합니다. 바로가기의 표시 이름만 바뀌며 설치 위치·앱 데이터·논문 자료는 그대로입니다.

### 앱과 규칙집 업데이트

- **앱 새 판 업데이트**: 창 맨 위 제목줄 오른쪽 끝의 **"업데이트"** 단추를 누릅니다. 확인 창에서 **"지금 설치"**를 누르면 앱이 닫혔다가 새 판으로 다시 열립니다. 새 사용자 설치의 자동 업데이트는 관리자 확인 없이 진행됩니다. (설치할 때 옛 **"모든 사용자"** 판 제거를 취소했어도 자동 업데이트에는 관리자 확인이 필요하지 않습니다.)
- **규칙집 업데이트**: 설정 화면의 **앱 정보 → 업데이트** 칸에서 새 규칙집을 확인하고 업데이트하거나 이전 규칙집으로 되돌릴 수 있습니다. 서명이 확인된 안전한 규칙집만 받아 적용하며, 도우미의 답변이나 진행 중인 작업이 끝나기를 잠시 기다립니다. 만약 업데이트하지 못했다는 안내가 나오면 작업이 끝난 뒤 **"다시 시도"**를 누르세요. 업데이트한 규칙집을 쓰고 있을 때는 **"이전 규칙집으로"** 단추를 눌러 보관된 이전 판(또는 앱에 원래 들어 있던 판)으로 되돌릴 수 있습니다. 업데이트에 실패하면 이전 판이나 앱에 원래 들어 있던 판으로 자동 복구됩니다.
- **업데이트를 확인할 수 없을 때**: 인터넷이 끊겨 업데이트를 확인할 수 없을 때도 지금 앱과 규칙집은 그대로 쓸 수 있습니다.
- **업데이트가 막혔을 때 (관리자 권한 실행 뒤)**: "앱을 관리자 권한으로 실행하지 마세요." 이전에 앱을 관리자 권한으로 실행했거나 보관 공간의 사용자가 달라지면 제목줄에 **"앱 업데이트 안내"** 단추가 뜹니다. 이 단추를 누르면 자동 업데이트를 사용할 수 없다는 안내 창이 열립니다. 안내 창의 **"내려받기 페이지 열기"**에서 새 판을 직접 받아 설치하세요. 이 상태가 계속되면 다음 업데이트도 같은 방법으로 설치해야 합니다.
- **업데이트 뒤 앱이 열리지 않을 때**: 업데이트 도중 파일 교체가 실패하면 옛 앱으로 자동 되돌아간다고 보장하지는 않습니다. 혹시 앱이 열리지 않으면 GitHub 릴리스에서 설치 파일을 다시 받아 설치하세요. 논문 작업 폴더와 자료는 그대로 남습니다.
