  - 상태: 확정 / 비어 있음 / 대체됨(→새ID)
  - 적용 판: 해당 결정이 적용되는 소프트웨어 판 번호(버전, 예: v0.6.0, v0.6.1, 공통)
  - 형님 원문: 형님이 직접 말씀하신 지시나 승인 문장 그대로 인용
  - 날짜: 결정이 내려진 날짜 (YYYY-MM-DD)
  - 출처: 원문이 기록된 대화, 메모리 파일, 문서 경로
